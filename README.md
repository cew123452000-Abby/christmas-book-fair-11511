# 聖誕閱讀奇遇｜聖誕節書展

為國小圖書館與閱讀推廣活動設計的聖誕節主題書展網頁。

## 網頁功能

- 70 本聖誕主題書目與實際書籍封面
- 依書名、作者或出版社搜尋
- 依閱讀主題與資料狀態篩選
- 依幼兒、低年級、中年級、高年級與國中以上篩選
- 書籍作者、出版社與內容簡介
- 個人閱讀清單與列印功能
- 四題聖誕閱讀心理測驗，依閱讀偏好推薦館藏
- 支援手機、平板及電腦操作
